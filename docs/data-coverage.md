## Findings (pulled 2026-10-21)

- **Betting lines** start in 2013 (≈96–100% of FBS games from 2013 on; none before).
- **Talent composite** starts in 2015 (partial in 2017, 2024, 2025).
- **CFP flag check passed:** 3 CFP games per season 2014–2023, 11 for 2024–2025 (12-team format), 0 before 2014.
- **Preseason poll labelling:** CFBD stores the preseason AP and Coaches polls as regular-season week 1, so poll week *w* reflects games through week *w*−1.
- **Coaches Poll** is missing for 2000 in CFBD.
- **2020** is short (570 FBS games) because of COVID.
